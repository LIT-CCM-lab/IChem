# grim - Graph interaction matching

`IChem grim` aligns **protein-ligand complexes** using a **graph matching** algorithm based on **interaction pseudoatoms**.
It produces an interaction-based alignment that can be quantified by empirical scores (including **GrScore**) and can be used to:

- align two complexes by **similarity of interaction patterns**
- compare docking poses to a reference interaction pattern (pose post-processing / rescoring)

`grim` works either from **structures** (protein + ligand) or directly from **interaction pseudoatom MOL2** files.

!!! important
    `grim` relies on interaction pseudoatoms similar to those generated by `IChem ints`.
    The **interaction generation options** (distance/angle thresholds, hydrophobic settings, etc.) are also available in `grim`.

---

## Synopsis

`grim` supports three modes.

### Mode 1 - Graph matching from structures

```bash
IChem grim <refProt.mol2> <refLig.mol2> <compProt.mol2> <compLig.mol2>
```

!!! note
    Use `--multim2` if ligand files are **multi-MOL2** in this mode.

### Mode 2 - Graph matching from interaction pseudoatoms

```bash
IChem grim <refInts.mol2> <compInts.mol2>
```

This mode expects interaction pseudoatoms (typically in merged form, e.g. `*_INTS_M.mol2`).

### Mode 3 - Post-process docking results (screening)

```bash
IChem grim <refProt.mol2> <refFile.mol2> <dockFile.mol2>
```

!!! note
    In this mode, `refFile` and `dockFile` can be **multi-MOL2** files.

---

## What `grim` does

At a high level, `grim`:

1. Builds interaction pseudoatoms for reference and comparison complexes (or reads them directly in mode 2).
2. Represents interactions as a **graph** where nodes are pseudoatoms and edges encode geometric relations.
3. Searches for **cliques** (compatible subgraphs) that maximize interaction pattern similarity.
4. Produces an alignment (protein + ligand coordinates) and reports scoring metrics.

---

## Inputs

### Mode 1 (structures)
- `refProt.mol2`: reference protein binding site (MOL2)
- `refLig.mol2`: reference ligand (MOL2, can be multi-MOL2 with `--multim2`)
- `compProt.mol2`: comparison protein binding site (MOL2)
- `compLig.mol2`: comparison ligand (MOL2, can be multi-MOL2 with `--multim2`)

### Mode 2 (pseudoatoms)
- `refInts.mol2`: reference interaction pseudoatoms (typically merged)
- `compInts.mol2`: comparison interaction pseudoatoms (typically merged)

### Mode 3 (docking)
- `refProt.mol2`: reference protein binding site (MOL2)
- `refFile.mol2`: reference ligand pose(s) (MOL2 or multi-MOL2)
- `dockFile.mol2`: docked pose set (MOL2 or multi-MOL2)

---

## Outputs

Whatever the mode, `grim` typically produces **7 output files** in the working directory:

| File | Description |
|---|---|
| `RefInts.mol2` | Reference interaction pseudoatoms (merged mode) |
| `CompInts.mol2` | Interaction pseudoatoms (merged mode) of the complex to fit |
| `GRIM_ints.mol2` | Aligned interaction pseudoatoms of the complex to fit |
| `GRIM_lig.mol2` | Fitted ligand coordinates (aligned to reference) |
| `GRIM_prot.mol2` | Fitted protein coordinates (aligned to reference) |
| `GRIM.log` | Verbose alignment log |
| `Grifp_res.csv` | Summary table (appended after each run) |

In screening mode (mode 3), you will also typically obtain a results table such as:
- `Grimscreen_res.tsv` (full results per pose)
- `GrScreen.csv` (summary; naming may depend on the build/version)

## Options

### General options

| Option | Default | Description |
|---|---:|---|
| `-rn <name>` | `Ref` | Reference name shown in outputs |
| `-cn <name>` | `Comp` | Comparison name shown in outputs |
| `--values` | - | Output **scores only** (no alignment files) |
| `-sim <0|1>` | `0` | Similarity flag stored in result tables |
| `-outInt <mode>` | `MERG` | Output only one interaction positioning (`MERG`, `LIG`, `CENT`, `PROT`) |
| `-match <mode>` | `MERG` | Align using only a specific positioning (`MERG`, `LIG`, `PROT`, `CENT`) |
| `-score <STD|FCT>` | `FCT` | Scoring method (`STD` or scoring function `FCT`) |
| `--newH` | - | Less permissive definition of hydrophobic interactions |
| `--multim2` | - | Enable multi-MOL2 ligand handling (mode 1) |

!!! note
    `-outInt` is not useful when used with `--values` (scores-only mode).

### Interaction positioning (`-outInt`)

- `MERG`: all aligned interactions are output
- `LIG`: ligand-positioned pseudoatoms
- `CENT`: centered pseudoatoms
- `PROT`: protein-positioned pseudoatoms

### Matching position (`-match`)

- `MERG`: align using **all** interaction points
- `LIG`: align using ligand interaction points only
- `PROT`: align using protein interaction points only
- `CENT`: align using centered interaction points only

### Alignment options

| Option | Default | Description |
|---|---:|---|
| `-max <N>` | `1` | Maximum number of output cliques |
| `-size <N>` | `3` | Minimal size of a clique |
| `--all_cliques` | - | Detect all cliques (not only maximal) |
| `-dsame <N>` | `0.5` | Max distance difference between two *similar* points (e.g., LIG-LIG) |
| `-dclose <N>` | `0.75` | Max distance difference between *close* points (e.g., LIG-CENT, PROT-CENT) |
| `-dfar <N>` | `1.0` | Max distance difference between *far* points (e.g., LIG-PROT / cross-position constraints) |

!!! note
    Distances are typically in Å. Defaults may depend on IChem version/build.
    For authoritative defaults, run: `IChem grim -h`.

## Result tables

### `Grifp_res.csv` (appended after each run)

`Grifp_res.csv` is a summary of the GRIM alignment and is appended at every new `grim` command.

Typical columns:

- `NCli` : clique id (starts at 0 or 1 depending on build)
- `Ref`  : reference name (`-rn` or protein name)
- `Comp` : comparison name (`-cn` or protein name)
- `Simil`: similarity flag (from `-sim`)
- `LIG`  : number of matched ligand-positioned pseudoatoms
- `CENTER`: number of matched centered pseudoatoms
- `PROT` : number of matched protein-positioned pseudoatoms
- `SumCl`: clique-based score
- `RMSD` : RMSD (Å) of the clique
- `RLig`, `RCent`, `RProt`: number of reference pseudoatoms for each positioning
- `CLig`, `CCent`, `CProt`: number of comparison pseudoatoms for each positioning
- `GrSc` : Grim score (empirical score)
- `RMSDAl`: RMSD (Å) of the clique according to GrScore
- `NPol` : number of matched polar interaction pseudoatoms

### Screening output (`Grimscreen_res.tsv`)

In mode 3, every docked pose is matched to the reference and scored.
The results file contains one line per pose with the same core metrics as `Grifp_res.csv`.
You typically select poses by **highest `GrSc`** and/or low alignment RMSD, rather than docking score alone.

## Examples

### Example 1 - Align two complexes from structures (mode 1)

```bash
IChem -sim 1 -rn 2rh1 -cn 4amj grim 2rh1_prot.mol2 2rh1_lig.mol2 4amj_prot.mol2 4amj_lig.mol2
```

Expected outputs include:
`RefInts.mol2`, `CompInts.mol2`, `GRIM_ints.mol2`, `GRIM_lig.mol2`, `GRIM_prot.mol2`, `GRIM.log`, `Grifp_res.csv`.

### Example 2 - Align from interaction pseudoatoms (mode 2)

```bash
IChem -sim 1 -rn 2rh1 -cn 4amj grim 2rh1_INTS_M.mol2 4amj_INTS_M.mol2
```

This mode is useful if you already generated interaction pseudoatoms using `IChem ints`.

### Example 3 - Docking post-processing / rescoring (mode 3)

```bash
IChem -sim 1 grim site.mol2 ligand.mol2 docked.mol2
```

Where:
- `ligand.mol2` is the reference pose (e.g., X-ray pose)
- `docked.mol2` contains multiple docked poses (multi-MOL2)

The output ranking is based on interaction graph similarity score (**GrSc**).

---

## Practical guidance

- Use mode 2 if you want to decouple **interaction generation** from matching (e.g., precompute `*_INTS_M.mol2` once).
- In pose selection workflows (mode 3), the best interaction-similarity pose may not be the top-ranked docking-score pose.
- Tune `-size`, `-max`, and `-dsame/-dclose/-dfar` if you need more permissive matching or want to explore alternative alignments.
